# Google Maps setup

Checkout validates the buyer's map pin against server-only `STORE_LAT` and `STORE_LNG` with an 8 km Haversine limit. The buyer selects a pin by clicking the map; coordinates are stored in hidden form fields and an embedded Google Maps preview follows the selection. The picker uses OpenStreetMap tiles so it does not need a Maps API key. Admins can open each saved pin directly in Google Maps. The local `.env.local` uses the published point for Titik 0 Derajat Dieng (`-7.204176, 109.911214`) as an initial reference. Confirm the exact business origin with the owner before production, since the service radius depends on it. For Google Maps JavaScript map controls or Places address autocomplete, supply and restrict a browser key by origin/API, and keep geocoding secrets server-side.
